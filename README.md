# DS42S-B

### Shree Dashashremali 42 Gnati Suraksha Samiti — Backend API Server

Robust Node.js + Express.js REST API with MongoDB & Mongoose.

#### Key Features:
- Sole Director JWT Authentication & BCrypt hashing
- 17 Mongoose Models with exact Integer Paise monetary calculations
- Atomic multi-document database transactions
- Dynamic year-wise installments & automated dues generation
- Bulk / Group Cheque Payment Allocation Engine with Equal Split & Custom Distribution
- Cheque Clearance Lifecycle (Received, Deposited, Cleared, Bounced)
- Running Financial Ledger with verified running balances
- Death Claim Eligibility Engine enforcing 100% dues clearance
- Claim Cheque Issue, Handover, and Disbursement
- 15 Comprehensive Reports with Excel (.xlsx) export
- Immutable Director Audit Trail
- Automated end-to-end test suite (`tests/test_all_modules.js`)
